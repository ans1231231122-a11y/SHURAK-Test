شُرَاك | SHURAK - سوقك الطلابي
================================

نسخة أولية جاهزة للتشغيل (بدون مجلدات)

الملفات الموجودة:
-----------------
index.html          → واجهة الموقع الكاملة
style.css           → التصميم (RTL + أزرق وأبيض)
app.js              → المنطق (منتجات، سلة، تسجيل دخول تجريبي)
firebase-config.js  → إعدادات Firebase (جاهز للربط)
firestore.rules     → قواعد حماية قاعدة البيانات
shurak-banner.jpg   → صورة البنر التسويقي
README.txt          → هذا الملف

طريقة التشغيل السريعة:
----------------------
1. افتح المجلد في أي محرر أو اسحب index.html إلى المتصفح.
2. أو استخدم خادم محلي بسيط:
   - Python:  python -m http.server 8080
   - ثم افتح: http://localhost:8080

ما يعمل حالياً (المرحلة 1 + جزء من 2 و 3):
------------------------------------------
✓ تصميم حديث RTL متجاوب
✓ شريط علوي (شعار + بحث + تسجيل + سلة)
✓ قسم Hero مع البنر
✓ أقسام المنتجات
✓ شبكة منتجات تجريبية مع فلترة وبحث
✓ سلة مشتريات (محفوظة في localStorage)
✓ محاكاة تسجيل الدخول بـ Google
✓ صفحة حسابي (تعديل الجوال والمدينة والعنوان)
✓ إنشاء طلب تجريبي
✓ قواعد Firestore جاهزة

ما يحتاج تفعيله لاحقاً (Firebase):
---------------------------------
1. أنشئ مشروع Firebase
2. فعّل Authentication → Google
3. أنشئ Firestore Database
4. انسخ الإعدادات إلى firebase-config.js
5. أضف مكتبات Firebase في index.html
6. استبدل دالة simulateGoogleLogin بالدالة الحقيقية
7. اربط المنتجات والطلبات بـ Firestore

ملاحظات أمان مهمة:
------------------
- لا تضع مفاتيح Service Account في الملفات العامة أبداً.
- استخدم قواعد firestore.rules المرفقة.
- في الإنتاج أضف حقل role في مستند العميل (user / seller / admin).

مراحل التطوير المقترحة:
-----------------------
المرحلة 1: الواجهة + المنتجات التجريبية          ← تمت
المرحلة 2: تسجيل Google الحقيقي + حسابات العملاء
المرحلة 3: السلة السحابية + المفضلة + الطلبات
المرحلة 4: لوحة الإدارة + نظام البائعين + الدفع

للتواصل أو التطوير الإضافي:
---------------------------
